# 默认文章标题提示词设计

日期：2026-08-11
状态：已批准并实施

## 1. 目标

默认情况下，无论用户要求生成访谈整理、分析报告、科普文章、要点解读或其他文章类型，Gemini 都应输出一个根据视频内容总结的文章标题。

如果用户明确要求无标题、只输出正文，或指定了不包含标题的特殊格式，则遵从用户要求省略标题。

## 2. 实现范围

只修改 Gemini 文章提示词，不增加新的模型调用、字幕抽样、服务端标题校验、错误码或流式协议。

### 默认规则

- Markdown 第一行输出一个 `# 文章标题`；
- 标题由 Gemini 根据视频标题和本次提供的字幕内容概括；
- 不使用服务端固定模板拼接标题；
- 两阶段渐进生成时，只有第一阶段输出标题，续写阶段不得重复标题。

### 特殊要求

仅当用户要求明确表达以下意图时允许省略标题：

- “不要标题”或“无标题”；
- “只输出正文”；
- 用户指定的输出格式明确不包含标题。

模糊的风格、受众、篇幅或任务类型要求不视为省略标题。

## 3. Prompt 调整

文章公共规则从“必须输出一级标题”调整为“默认输出一级标题，除非用户明确要求省略”。

单次全文生成和渐进生成第一阶段使用相同的默认标题规则；渐进生成第二阶段保持“只追加新的二级章节，不重复一级标题”。用户要求仍不能覆盖事实忠实度、安全边界和 Markdown 安全规则。

## 4. 测试

- 未提供额外要求时，文章请求明确要求生成模型总结的一级标题；
- 用户只改变文章类型、风格或受众时，标题默认规则保持不变；
- 用户明确要求“不要标题”时，Prompt 允许省略标题；
- 渐进续写请求继续禁止重复一级标题。

测试验证发往 Gemini 的请求契约，不尝试用确定性单元测试判断模型标题文案质量。

## 5. 非目标

- 不保证标题一定覆盖完整视频的每个主题；
- 不验证标题是否与 YouTube 原标题相似；
- 不在服务端补写或修复标题；
- 不新增标题编辑、候选标题或重写功能；
- 不改变现有首字延迟和 5W1H 链路。
