# Default Article Title Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Gemini output a model-summarized Markdown article title by default for every article type, while allowing explicit no-title user requirements.

**Architecture:** Change only the shared article Prompt contract used by one-shot and progressive preview generation. Keep progressive continuation title-free, and verify the outbound Gemini request for default, style-only, and explicit no-title requirements.

**Tech Stack:** TypeScript, Vitest, Gemini REST request builders.

## Global Constraints

- Do not add model calls, transcript sampling, server-side title validation, or protocol changes.
- The title is generated by Gemini from the video title and transcript context; the server does not construct it.
- Only explicit requests such as `不要标题`、`无标题` or `只输出正文` may omit the title.
- Style, audience, task type, and length requests do not implicitly remove the title.
- Keep the progressive continuation request title-free so it cannot duplicate the first-stage title.

**Interfaces:**
- Consumes: `buildArticleRequest(input: ArticlePromptInput)` and `buildArticlePreviewRequest(input, previewTranscript)`.
- Produces: Gemini system instructions that default to one model-generated H1 while respecting explicit no-title requirements.

- [ ] **Step 1: Write the failing Prompt contract test**

Add a test that builds three article requests and asserts the outbound system/user payload:

```ts
it("defaults to a model-generated title unless the user explicitly asks to omit it", () => {
  const defaultRequest = buildArticleRequest({ transcript });
  const styledRequest = buildArticleRequest({
    transcript,
    requirement: "写成面向产品经理的简洁分析报告",
  });
  const noTitleRequest = buildArticleRequest({
    transcript,
    requirement: "不要标题，只输出正文",
  });

  const systemText = defaultRequest.systemInstruction.parts[0].text;
  expect(systemText).toContain("默认");
  expect(systemText).toContain("根据视频标题和字幕内容概括");
  expect(systemText).toContain("明确要求无标题");
  expect(styledRequest.systemInstruction.parts[0].text).toBe(systemText);
  expect(styledRequest.contents[0].parts[0].text).toContain("面向产品经理");
  expect(noTitleRequest.contents[0].parts[0].text).toContain("不要标题，只输出正文");
});
```
