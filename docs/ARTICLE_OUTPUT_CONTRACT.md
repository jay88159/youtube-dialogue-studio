# 主文章输出协议

## 目标

主文章不是视频摘要，而是一篇可独立阅读的中文长篇访谈编辑稿。协议来自参考视频 `xRh2sVcNXQ8` 的完整字幕与给定示例文章，但不把示例正文复制进 Prompt，也不硬编码视频观点。

## 固定约束

- 事实只来自视频标题、字幕和用户要求中合法的表达约束，不补造人物、数字或结论。
- 输出 Markdown：一个一级标题，随后按主题组织二级章节。
- 每章先给一行章节副标题，再以多轮对话展开观点、论据、例子、数字和分歧。
- 优先保留标题或字幕中明确出现、被直接称呼的说话人姓名；无法确认时使用“主持人”或“嘉宾”。
- 覆盖视频开头、中段和结尾，不把长视频压缩成只覆盖前几个主题的短摘要。
- 用户要求可以改变任务类型、风格、受众和篇幅，但不能覆盖事实边界和 Markdown 协议。
- 渐进生成的第一阶段只输出一个一级标题和开场章节；第二阶段只能追加新的二级章节，不得重复标题或开场论点。两阶段合并后仍是一篇连续文章。

## 自适应规模

| 视频时长 | 二级章节 | 默认正文长度 |
| --- | ---: | ---: |
| 小于 20 分钟 | 2–5 | 1800–3500 中文字符 |
| 20–44 分钟 | 5–8 | 3500–6000 中文字符 |
| 45 分钟及以上 | 8–12 | 6000–10000 中文字符 |

规模是默认编辑目标，不是截断规则。用户明确指定篇幅时遵从用户要求；模型输出仍受服务端 160 KiB 上限保护。

## 参考视频验收

无额外生成要求时，`xRh2sVcNXQ8` 必须满足：

1. 优先取得 YouTube 字幕轨道，或使用同一轨道生成的完整版本化快照；
2. 字幕超过 2000 个时间片段，并覆盖 80 分钟以上；
3. 第一个正文增量先于完成事件到达并在浏览器中可见；
4. 正文包含 8–12 个二级章节、6000–10000 个中文字符；
5. 章节主题覆盖技术历史、商业化、硬件、地缘竞争、监管、定价、模型生态和社会影响；
6. 完成后每章可使用服务端上下文生成固定六字段 5W1H。
